# Alerta Câmara

Aplicativo Android para organizar sessões de estudo e acompanhar a preparação para a prova de 17/01/2027.

## Versão 2.1

- Registro de check-ins com duração, sequência diária e histórico recente.
- Meta diária de check-ins e horas configurável no perfil.
- Compensação de dias sem check-in redistribuída até a data da prova.
- Coach motivacional ou extremamente exigente, com pressão proporcional ao prazo.

Desenvolvido por Mario Henrique Cezar.
